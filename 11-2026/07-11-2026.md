### Libghostty 1.0
Libghostty 1.0 is a stable, portable C library for terminal emulation, extracted from Ghostty. It now powers terminals in JetBrains IDEs, Neovim, KDE Konsole, and other tools, with over 12.5 million active users. The library supports bindings for Rust, Go, JavaScript, and more.

*Why it matters:* Libghostty 1.0 provides a stable, high-performance terminal emulation library that is already widely adopted, reducing fragmentation in terminal technology.
