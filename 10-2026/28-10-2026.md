### Apple's git still trusts the compromised eMudhra certificates
Apple's developer tools, including git, curl, and Python, still trust compromised eMudhra certificates as of October 28, 2026. The issue persists despite Apple being notified on October 17, and macOS 27.2 undid user-applied workarounds. Tools like git can now intercept HTTPS connections, allowing attackers to tamper with code and steal credentials.

*Why it matters:* This vulnerability exposes macOS users to man-in-the-middle attacks, enabling attackers to intercept and alter HTTPS traffic from critical developer tools.
