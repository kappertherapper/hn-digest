### Ladybird is now in alpha
The Ladybird browser, built with a custom engine from scratch, has entered alpha for macOS and Linux. It supports WebDriver and Firefox DevTools protocol, with automatic rolling updates planned.

*Why it matters:* Ladybird’s alpha release introduces a new contender in the browser space, emphasizing security and rapid iteration for developers and users.

### Spacecraft reaches Mercury on second-ever mission to enter its orbit
The BepiColombo mission successfully enters Mercury’s orbit, marking a historic milestone in space exploration. The spacecraft aims to study the planet’s surface and magnetic field.

*Why it matters:* This mission could unlock new insights into Mercury’s geology and the formation of our solar system.


### Nospeaker ─ Make your MacBook's trackpad talk using its haptic motor

*Why it matters:* Nospeaker showcases creative hardware hacking, turning a trackpad into a functional speaker for accessibility or fun.


### Win4wine – Run Windows Shell as the Linux Desktop on Wine
Win4wine allows users to run the Windows shell as a Linux desktop environment using Wine. It aims to bridge the gap between Windows and Linux workflows.

*Why it matters:* This tool could simplify transitions for users who rely on Windows applications but prefer Linux as their primary OS.


### VP ≠ VNP over Every Field
A formal math proof demonstrates that the complexity classes VP and VNP are not equal over every field. The result advances theoretical computer science and algebraic complexity theory.

*Why it matters:* This proof deepens our understanding of computational complexity, particularly in the context of algebraic and geometric problems.
