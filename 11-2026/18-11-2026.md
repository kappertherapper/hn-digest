### Java4Shell: RCE in OpenJDK when processing Base64
A critical vulnerability, Java4Shell (CVE-2026-114938), has been disclosed in OpenJDK’s Base64 decoder. The flaw allows remote code execution (RCE) with a CVSS score of 9.2, affecting widely used Java applications.

*Why it matters:* This vulnerability poses a severe risk to enterprises, as Java powers critical infrastructure across banking, aviation, and national security systems.
