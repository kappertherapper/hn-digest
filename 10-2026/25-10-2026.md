### Local Wikipedia: Wikipedia, but only for things a half hour walk from you
Local Wikipedia filters Wikipedia entries to only show places within a 30-minute walk from your current location. It dynamically adjusts the radius to include 25 to 500 closest geocoded pages. The tool emphasizes privacy by not sharing your location in shared links.

*Why it matters:* This project reimagines how we discover and interact with local information, blending geographic relevance with the depth of Wikipedia.

### Root shell on Samsung TV
A security researcher claims to have achieved root shell access on a 2025 Samsung TV, revealing privacy concerns and targeted ads. The exploit bypassed AES-encrypted firmware and required hardware-level intervention. Details are expected in a future write-up.

*Why it matters:* This highlights ongoing vulnerabilities in consumer electronics and the risks of opaque, proprietary firmware ecosystems.


### The Goose Programming Language
Goose is a memory-safe systems language with no heap allocator or garbage collector, using data stacks for memory management. It claims to outperform C++ and Rust in benchmarks while using less memory. The language avoids lifetime annotations and supports safe references without annotations.

*Why it matters:* Goose represents a novel approach to memory safety and performance, challenging traditional systems programming paradigms.

### Broccoli2Shell: Brotli decoder RCE in Node.js, Python and more
A vulnerability in the Brotli decoder (CVE-2026-111497) allows remote code execution in Node.js, Python, and other libraries using Google's C decoder. Crafted compressed data can write past buffer bounds, requiring immediate patches.

*Why it matters:* This security flaw affects widely used platforms and underscores the risks of relying on third-party compression libraries.
