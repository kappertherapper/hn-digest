### Why get an expensive Pi when I have an old phone?
A developer argues that recycled 5G smartphones offer better value than Raspberry Pi for embedded projects, combining cameras, GPS, storage, and connectivity in one device. The post compares costs and capabilities of using a Redmi or Huawei phone versus a Pi-based setup.

*Why it matters:* It challenges the assumption that dedicated single-board computers are always the best choice for hardware projects, highlighting cost efficiency and integrated features.


### Ggml v1.0.0
The ggml library, a framework for machine learning models, reaches version 1.0.0 with a stable release. The update includes performance improvements and expanded compatibility for AI workloads.

*Why it matters:* A major milestone for ggml, signaling its readiness for production use in AI applications.


### Monkey Island: all 13 versions side by side
A website showcases all 13 versions of 'The Secret of Monkey Island' running simultaneously in a retro terminal-style interface. The project preserves the original text-mode aesthetic while allowing side-by-side comparisons.

*Why it matters:* A nostalgic and technical showcase of classic game preservation, demonstrating how old software can be archived and compared.

### Italy fines Meta $887M over Android users' data access
Italy's data protection authority fines Meta nearly $900M for improperly accessing Android users' data. The ruling addresses violations of GDPR and user consent requirements.

*Why it matters:* A major regulatory action against Meta, reinforcing accountability for data privacy violations.


### PyPI's redesigned project pages with clearer security signals are now live
PyPI has updated its project pages to highlight security signals like provenance states and warnings. The redesign aims to help developers assess package safety more easily.

*Why it matters:* Improves transparency and security for Python developers, reducing risks from malicious or compromised packages.


### Generative AI uses more energy on non-English text
Research from the University of Michigan finds that generative AI models consume more energy when processing non-English text. The study highlights inefficiencies in multilingual AI workloads.

*Why it matters:* Raises concerns about the environmental impact of AI, particularly for non-English language processing.


### Lovable apps expose passport details and more than 200K private messages
A security audit reveals that apps built with Lovable, an AI-powered development platform, exposed sensitive data like passport details and private messages. Over 159,000 projects were analyzed.

*Why it matters:* Exposes risks in low-code AI platforms, where ease of use may compromise data security.


### Italy fines Meta €805M over photo privacy
Italy's data protection authority issues another fine against Meta, this time for €805M over photo privacy violations. The ruling addresses improper handling of user photos.

*Why it matters:* Another regulatory blow to Meta, emphasizing repeated failures in user data protection.


### Show HN: A terminal-native idle factory game, written in Rust with ratatui
A developer releases 'terminactory,' a terminal-based idle factory game built in Rust using the ratatui library. The game runs entirely in the command line.

*Why it matters:* Showcases Rust's capabilities for terminal-based applications, offering a unique gaming experience.


### Advancing science and engineering with Antigravity's /teamwork
