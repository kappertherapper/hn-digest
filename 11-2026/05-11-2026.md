### sshole
A critical flaw in OpenSSH on musl libc-based systems (like Alpine Linux) allows password authentication bypass for accounts with a * password field. Attackers can log in without a valid password by sending a long password string (257+ bytes). The issue stems from musl libc's handling of crypt() failures, returning a * character instead of NULL.

*Why it matters:* This vulnerability exposes millions of systems running Alpine Linux or Docker images based on it, enabling trivial remote access to key-only accounts.


### Alpine Linux Security Advisory: OpenSSH-server password authentication bypass
Alpine Linux has issued a security advisory for a critical OpenSSH-server flaw affecting all supported releases. The advisory details how attackers can exploit the vulnerability to bypass password authentication on systems with specific account configurations. Users are urged to update openssh-server and restart the daemon.

*Why it matters:* The flaw impacts default configurations in Alpine Linux, including root and key-only users, making it a widespread and urgent security risk.
