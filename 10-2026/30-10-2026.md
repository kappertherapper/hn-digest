### Backdoor in Claude Code for VS Code extension on the Cursor Marketplace
A backdoored version of the official Claude Code for VS Code extension was discovered on the Cursor Marketplace, dropping a persistent SSH backdoor across macOS, Linux, and Windows. The compromised extension (version 2.1.313) was removed from Cursor, NPM, and VSCode registries after detection. The attack highlights risks of supply-chain compromises in developer tools.

*Why it matters:* This incident underscores the critical need for rigorous security vetting of extensions and developer tools, which have privileged access to sensitive code and systems.

### Azure's Weakest Link – Five Full Cross-Tenant Compromises
A security researcher uncovered five critical vulnerabilities in Azure’s API Connections, enabling full cross-tenant compromises of Key Vaults and Azure SQL databases. The flaws stem from flawed input validation in Azure Logic Apps, allowing attackers to access victim resources. The researcher earned $200,000 for reporting these issues.

*Why it matters:* The vulnerabilities expose a systemic risk in Azure’s architecture, threatening data isolation and cross-tenant security for cloud services.

### Why a program doesn't work when run from a batch file, but works when clicked

The issue stems from differences in the working directory and environment variables between the two execution methods. Chen provides a workaround using the `start` command.

*Why it matters:* Understanding these nuances helps developers avoid subtle bugs in Windows batch scripting and automation.
