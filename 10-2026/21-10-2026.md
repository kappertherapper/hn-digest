### PHP 8.2.35
PHP released version 8.2.35 to address two critical remote code execution (RCE) vulnerabilities. These flaws could allow unauthenticated attackers to execute arbitrary code on servers running PHP under specific conditions.

*Why it matters:* Given PHP's widespread use, this security update is critical to prevent widespread server compromises and data breaches.


### Eight Bits of Trust; eMudhra's CA keys cracked in milliseconds
Security researcher Scott Helme discovered that eMudhra's certificate authority (CA) private keys were weak, allowing trivial recovery in milliseconds. The compromised keys were used for TLS and code-signing certificates, leading to revocations by major browsers.

*Why it matters:* This highlights the catastrophic risks of weak cryptographic keys in CA infrastructure, undermining trust in digital certificates and secure communications.


### PHP2Shell: AI uncovers critical RCE in PHP

*Why it matters:* The discovery underscores the growing role of AI in identifying critical security flaws and the urgent need for widespread PHP updates.
